# ADAB-TERHADAP-RAKAN
Untuk kuiz padankan situasi &amp; 3 adab:  Buat kuiz interaktif kanak-kanak (LEVEL 2 ADABKU) padankan 3 situasi rakan (pensel jatuh, kata tolong/terima kasih, kawan sedih) dengan Membantu Rakan, Bercakap Dengan Sopan dan Menghormati Rakan. Ada skor bintang, bunyi ceria dan mesej galakan bila salah.
